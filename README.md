# Pong Game

A simple browser-based Pong game built with HTML, CSS, and JavaScript.

## How to play

- Move the left paddle with your mouse or the **Up** and **Down** arrow keys.
- The right paddle is controlled by the computer.
- Press **Space** to pause or resume.
- Use **Restart Game** to reset the score.

Open `index.html` in a browser to play.
